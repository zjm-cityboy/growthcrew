## 面试前 15 分钟速刷清单（数字锚点全部有注释来源）

- **产品**：面向自学者的成长执行系统——贴入参考计划，教练 Agent 对齐排程，审批生效，每日打卡带卡因，周复盘纠偏（P2）。不制造焦虑：断签只归因不惩罚。
- **架构**：3 个 LLM Agent（总编 P2/教练/复盘师 P2）+ 确定性管家（定时任务零 LLM）；HITL 审批在服务层不在图里（ADR-0003）。
- **规模**：11 张表（0001×2 + 0002×9 + 0003 加列）；**53 个测试用例**双库跑（SQLite + 真 PostgreSQL 16）；覆盖率 **83%**（门禁 80%）；mypy strict **70 文件零问题**；**5 轮无偏代码审查共 44 项发现全部修复**（12+6+8+11+3，含 2 个 P0）。
- **质量门禁**：CI 四关 = ruff lint / ruff format / mypy strict / pytest；push 即跑双库 + 迁移冒烟（up→down→up）。
- **成本口径（勿吹）**：晨推零 LLM；教练一次导入约 5-8 次模型调用；用户 BYOK 自带密钥（Fernet 加密落库），开发者侧边际成本≈0。

## 口径纪律（防穿帮红线）

1. 说"**3 个** LLM Agent"，不要说 4 个——管家是确定性代码，这正是卖点；
2. 说"图很小（三节点）**故意**的"——LangGraph 的价值是声明式骨架与可扩展，不是图越花越好；
3. 简历技术栈与项目经历**尚未定稿**，等 P2 完整飞轮 + 3 天真实使用数据后再写；
4. 不用"高并发"等词（那是爬虫项目的事），本项目关键词是：**多 Agent 编排、HITL、双库测试、代码审查文化**。
