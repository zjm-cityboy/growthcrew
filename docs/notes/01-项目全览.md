## 一、产品定位

**一句话**：面向自学者的成长执行系统——贴入计划或写一句话，教练 Agent 排进每天，打卡带卡因，周报给"它懂我"级洞察，审批生效（HITL）。自托管 + BYOK。

**核心理念**（产品灵魂）：
1. **不制造焦虑**：断签只归因不惩罚；每日核心 ≤3 件写进排程算法；昨日 0 完成不报数字
2. **少即是多**：待办清单的死穴是无限膨胀，我们做"调度大脑"不做"更长的清单"
3. **数据自主**：一键 CSV 导出，你的成长数据是你的

**架构**：3 个 LLM Agent（教练/复盘师/陪练）+ 1 个确定性管家（晨推/统计零 LLM）。

## 二、四个架构决策（ADR 精华）

### ADR-0001: PWA 优先，不做原生 App

- **为什么**：solo 开发做原生偏离 Agent 主线；PWA 零新增技术栈
- **迁移路径写死**：后端 API-first（业务逻辑 100% 服务端），将来 Expo 重写 UI 壳 1-2 周
- **触发条件**：用户要小组件 / 推送拖留存 / 商店分发需求
- **面试一句话**："我用 PWA 先验证产品假设，同时用 API-first 架构保证原生迁移只换壳——还把触发条件定义成了可观测的数据指标。"

### ADR-0002: 只在"见机行事"处用 Agent

- **判断标准**：下一步是否依赖上一步的结果**临场决定**
- 正例：教练看到排程超载 → 自己下调再重排
- 反例：晨间摘要（固定查询+模板）→ 写死，零 LLM
- **面试一句话**："知道什么时候不用 Agent，比会用 Agent 更值钱。"

### ADR-0003: HITL 审批放服务层，不用 interrupt

- **为什么不用 interrupt**：图节点闭包持有请求 A 的 DB 会话，请求 B 恢复时该会话已关；跨请求会话管理复杂度不成比例
- **改为**：plan_proposals 表（PENDING），approve/reject 是条件 UPDATE 原子操作，重启天然免疫
- **面试一句话**："interrupt 适合'对话中插一嘴'，服务层审批适合'关掉 App 明天再批'。"

### ADR-0004: token 存 localStorage 的显式取舍

- **迁移条件写死**：引入第三方 JS / 开放注册 / 出现 XSS 修复记录
- **面试一句话**："这不是永久决定，是带触发条件的分期决策。"

## 五、踩坑实录（全部实测，面试"你踩过什么坑"的弹药）

| # | 坑 | 根因 | 修法 |
|---|---|---|---|
| 1 | alembic.ini 中文注释崩溃 | Windows GBK 编码读 UTF-8 | ini 纯 ASCII |
| 2 | `date: date` TypeError | 字段名遮蔽类型名 | 注解写字符串 `"_date"` |
| 3 | MissingGreenlet | async 禁止惰性加载 | `lazy="selectin"` |
| 4 | fastmcp 函数名遮蔽导入 | `@mcp.tool` 装饰器改变名字绑定 | 导入改别名 `run_scheduler` |
| 5 | openai 默认 600s 超时 | Agent 串行调用会拖死 | `timeout=30, max_retries=1` |
| 6 | uvicorn cwd 漂移 | 后台启动时目录重置 | 启动前显式 `cd backend` |
| 7 | SQLite vs PG 时间口径 | 朴素 UTC vs timestamptz | `cn_day_start_utc_naive()` |
| 8 | 迁移枚举缺 length | ORM VARCHAR(20) vs 实际 VARCHAR(2~7) | 迁移统一 `length=20` |
| 9 | upsert check-then-write 竞态 | 并发首写撞唯一约束 → 500 | `except IntegrityError: rollback → 更新` |
| 10 | httpx 写在 dev extras | Docker 镜像 `pip install .` 不装 extras → **容器无法启动** | 移入主 dependencies |
| 11 | Docker 部署链三重断裂 | 缺 GC_ENCRYPTION_KEY + 缺 agents/jobs + 缺 apscheduler | 全部补齐 |
| 12 | `result.all()` 只能消费一次 | 第二次调用返回空列表 | 先取回再抽取 |
| 13 | WeeklyReport 首插缺 NOT NULL | 先建空对象再补字段在 flush 时炸 | 全字段一次构造 |
| 14 | Python 写了 JS 布尔 | `true/false` 而非 `True/False` | json={} 里写 Python 布尔 |

## 七、口径纪律（防穿帮红线）

1. 说"**3 个** LLM Agent"，不说 4 个——管家是确定性代码
2. 说"图很小（三节点）**故意**的"——LangGraph 价值在骨架不在花哨
3. 不用"高并发"（那是爬虫项目）——关键词是**多 Agent 编排、HITL、双库测试、代码审查文化**
4. **竞品口径勿混**：爬虫项目说"礼貌限速"，本作品说"多 Agent 编排"
